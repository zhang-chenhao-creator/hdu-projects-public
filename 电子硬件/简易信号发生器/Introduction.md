# STM32F407 简易信号发生器与采集系统

## 1. 项目概览

本项目是基于 STM32F407 微控制器的嵌入式系统，实现了以下主要功能：
*   **多波形信号发生器**：能够输出正弦波、三角波、锯齿波和方波。
*   **波形参数调节**：支持频率调节（正弦/三角/锯齿/方波）和占空比调节（仅方波）。
*   **信号采集与回传**：通过 ADC 采集外部模拟信号，并通过 UART 串口发送给上位机（如示波器软件）。
*   **人机交互界面**：使用 OLED 显示当前模式、频率、占空比等信息，并通过按键进行控制。

## 2. 硬件架构与引脚配置

### 2.1 核心控制器
*   **MCU**: STM32F407ZGT6 (或兼容型号)
*   **主频**: 84 MHz (配置为 HSI 16MHz -> PLL -> 84MHz)

### 2.2 引脚映射

| 功能模块 | 引脚 | 模式/复用功能 | 说明 |
| :--- | :--- | :--- | :--- |
| **信号输出** | PA5 | Analog / AF_PP (TIM2_CH1) | **DAC_OUT2** (用于正弦/三角/锯齿波) 或 **TIM2_PWM** (用于方波) |
| **信号输入** | PA0 | Analog Mode | **ADC1_IN0**，用于采集模拟信号 |
| **按键输入** | PE3 | Input (Active Low) | **SW2**：短按调节频率，长按调节占空比 |
| | PE5 | Input (Active Low) | **SW3**：短按切换波形，长按进入菜单 |
| **显示屏** | I2C | I2C1 (PB6/PB7) | 0.96寸 OLED 显示屏 (SSD1306 驱动) |
| **串口通信** | PC12 / PD2 | UART5_TX / RX | 波特率 921600，用于发送 ADC 采样数据 |

## 3. 软件架构与文件功能

### 3.1 文件结构

*   `Core/Src/main.c`: 主程序入口，包含主循环、按键扫描逻辑、模式切换逻辑和 ADC 轮询逻辑。
*   `Core/Src/tim.c`: 定时器配置，包含方波生成函数 `Set_Square_Wave`。
*   `Core/Src/oled.c`: OLED 屏幕驱动，实现了字符、汉字显示和菜单绘制功能。
*   `Core/Src/usart.c`: 串口驱动，实现了 `UART_Send_Waveform_Point` 发送函数。
*   `Core/Src/stm32f4xx_it.c`: 中断服务函数入口（本项目主要依赖 HAL 库回调或轮询）。
*   `CMakeLists.txt`: CMake 构建脚本，配置了交叉编译工具链和编译选项。

## 4. 详细逻辑与数学原理

### 4.1 波形生成原理

项目采用两种方式生成波形：

1.  **DAC + DMA + Timer (正弦波、三角波、锯齿波)**
    *   **原理**: 预先计算波形的一个周期数据（100个采样点 `WAVE_SAMPLES`）存入数组，利用 DMA 将内存数据搬运到 DAC 寄存器。
    *   **频率控制**: 使用 **TIM6** 作为 DAC 的触发源。改变 TIM6 的溢出频率即可改变 DAC 输出点的更新速率，从而改变波形频率。
    *   **数学公式**:
        *   输出频率 $f_{out}$，采样点数 $N=100$。
        *   DAC更新频率 $f_{update} = f_{out} \times N$。
        *   TIM6 定时器时钟 $f_{clk} = 84 \text{ MHz}$。
        *   TIM6 自动重装载值 $ARR = \frac{f_{clk}}{f_{update}} - 1$。

2.  **PWM (方波)**
    *   **原理**: 使用 **TIM2** 通道 1 (PA5) 的 PWM 模式直接由硬件产生方波。
    *   **频率控制**: 修改 TIM2 的 ARR (Auto-Reload Register)。
    *   **占空比控制**: 修改 TIM2 的 CCR (Capture Compare Register)。
    *   **数学计算**:
        *   $ARR = \frac{84,000,000}{f_{out}} - 1$
        *   $CCR = \frac{(ARR + 1) \times Duty}{100}$

### 4.2 信号采集 (ADC)
*   **配置**: ADC1 通道 0，12位分辨率。
*   **流程**: 主循环中非阻塞/阻塞方式启动 ADC 转换，读取数值 (0-4095)，然后通过串口以文本格式 `value\r\n` 发送。

### 4.3 优化说明 (2026-01-08)
*   **时钟修正**: 原代码配置中使用 HSI 但未启用 PLL，导致系统运行在 16 MHz，但计算逻辑假设 84 MHz。已修复 `SystemClock_Config`，启用 PLL 将主频倍频至 **84 MHz**，确保频率计算准确。
*   **代码一致性**: 更新了 `tim.c` 中的方波计算逻辑，使其与修正后的 84 MHz 时钟保持一致。

## 5. 编译与运行
项目使用 CMake 构建系统。
1.  配置: `cmake -S . -B build -G Ninja`
2.  编译: `cmake --build build`
3.  烧录: 使用 OpenOCD 或 STM32CubeProgrammer 烧录生成的 `.elf` 或 `.hex` 文件。

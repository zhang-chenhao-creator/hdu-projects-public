# STM32 波形发生器与测量系统

本项目基于 STM32F407 开发板，实现了一个可调频率和占空比的多功能波形发生器，并具备实时波形采集与传输功能。

## 1. 硬件连接

*   **DAC 输出 (波形产生)**: `PA5`
    *   输出正弦波、三角波、锯齿波或方波。
*   **ADC 输入 (波形测量)**: `PA0`
    *   将 `PA5` 与 `PA0` 连接以进行自环测试，或接入外部信号。
*   **UART 输出 (上位机通信)**: `PC12 (TX)` / `PD2 (RX)`
    *   使用 UART5 发送 ADC 采样数据至电脑。
    *   波特率: **115200** (请在 usart.c 中确认实际配置)。
    *   配合 **VOFA+** 软件查看实时波形。
*   **交互按键**:
    *   `SW2` (PE3)
    *   `SW3` (PE5)
*   **显示**: OLED 屏幕 (I2C)

## 2. 按键操作说明

| 按键 | 操作类型 | 功能描述 | 备注 |
| :--- | :--- | :--- | :--- |
| **SW2** (PE3) | **短按** | **增加频率** | 根据当前频率范围自动调整步进 (+10Hz / +100Hz / +1000Hz) |
| **SW2** (PE3) | **长按** (>1s) | **调节占空比** | 仅在 **方波 (Square)** 模式下有效，每次增加 10% (10% -> 90% 循环) |
| **SW3** (PE5) | **短按** | **切换波形模式** | 方波 (Square) -> 三角波 (Triangle) -> 锯齿波 (Sawtooth) -> 正弦波 (Sine) -> 循环 |
| **SW3** (PE5) | **长按** (>1s) | **切换屏幕页面** | **菜单模式**: 按下>1s显示列表，>1.5s选中下一页，松开确认跳转。<br>列表: Info -> Mode -> Freq -> Duty |

## 3. OLED 显示页面

1.  **Page 0**: Demo 信息页 (Author / Contributor A / Demo ID)
2.  **Page 1**: 当前波形模式 (e.g., "Mode: Sine")
3.  **Page 2**: 当前频率值 (e.g., "Freq: 1000 Hz")
4.  **Page 3**: 当前占空比 (e.g., "Duty: 50 %") *仅方波有效*

## 4. 功能实现原理

*   **方波**: 使用 `TIM2` (PWM 模式) 直接翻转 GPIO 产生，频率调节通过修改 ARR 寄存器，占空比修改 CCR 寄存器。
*   **模拟波形 (正弦/三角/锯齿)**: 使用 `DAC` + `DMA` + `TIM6` + Look-up Table。
    *   `TIM6` 作为触发源，定时触发 DAC 转换。
    *   `DMA` 自动搬运内存中的波形表 (Look-up Table) 到 DAC 数据寄存器，实现无 CPU 干预的高速波形输出。
    *   频率调节通过修改 `TIM6` 的溢出频率实现。
*   **波形采集**: 使用 `ADC1` 轮询采集，并通过 `UART5` 发送 ASCII 码至上位机。

## 5. 编译与烧录

本项目使用 **VS Code + CMake + Ninja + Arm GCC** 构建。

*   **编译**: `Ctrl + Shift + B` (或点击底部的 Build)
*   **烧录 (不调试)**: `Ctrl + F5` (已配置 Task)
*   **调试**: `F5`

## 6. 使用示例

1.  上电后默认显示 Demo 信息页。
2.  短按 **SW3** 切换到 "Mode: Square" (方波)。
3.  短按 **SW2** 调节频率，长按 **SW2** 调节占空比。
4.  连接 `PA5` 到示波器观察波形。
5.  连接 `PA5` 到 `PA0`，打开电脑 VOFA+ 软件，观察实时采集的波形。

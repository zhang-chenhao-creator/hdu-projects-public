# Sorting Algorithm Benchmark

Console-based sorting algorithm benchmark tool written in C.

## Technical Highlights

- Implements five classic sorting algorithms: Bubble Sort, Selection Sort, Insertion Sort, Quick Sort, and Merge Sort.
- Performance benchmarking with timing measurements for each algorithm.
- Supports configurable array sizes for scalability testing.
- Modular structure with separate functions for each sorting algorithm.
- Generates benchmark output reports comparing algorithm efficiency.

## Public Scope

The repository includes source code and sample benchmark output. Generated executables and local runtime files are excluded.

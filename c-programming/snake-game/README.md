# Console Snake Game

Windows console snake game written in C.

## Technical Highlights

- Double-buffer style console rendering.
- Keyboard input handling for real-time movement.
- Collision detection for walls and snake body.
- Food generation, scoring, game-over handling, and screen layout logic.
- Single-file implementation kept for easy inspection.

## Public Scope

The repository includes source code only. Generated executables and local runtime files are excluded.

# Student Record System

Console-based student record manager written in C.

## Technical Highlights

- Linked-list based student and user records.
- Role-based user model for administrator, teacher, and student workflows.
- File persistence for records and user data.
- Modular structure split across menu handling, file I/O, student operations, user authentication, and utility helpers.
- Makefile included for a simple command-line build.

## Public Scope

The source contains placeholder demo accounts for local testing. No real student records, class data, or private account information are included.

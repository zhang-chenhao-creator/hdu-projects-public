# C Programming

This folder contains compact C projects focused on data structures, file I/O, console interaction, and simple numerical modeling.

## Projects

- `student-record-system`: a menu-driven student record manager using linked lists, user roles, file persistence, and validation helpers.
- `linear-regression-house-price`: a small linear regression implementation split into data loading, training, prediction, and verification modules.
- `snake-game`: a Windows console snake game with buffered drawing, keyboard input, collision detection, and score tracking.

The projects are kept as source-focused examples. Generated executables, private datasets, and local runtime files are not included.

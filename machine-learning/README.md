# Machine Learning

This folder contains compact machine-learning projects with source code, small reproducible examples, and implementation notes.

## Projects

- `iris-classification`: iris flower classification in Python and C, including KNN, decision tree, SVM-oriented C modules, a GUI, and visualization helpers.
- `isolet-letter-recognition`: CUDA/C implementation for ISOLET English-letter speech feature recognition.

Datasets, compressed archives, trained model binaries, build outputs, and training logs are excluded from the public repository.

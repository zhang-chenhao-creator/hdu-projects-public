# Iris Classification Project

Machine learning iris flower classification implemented in both Python and C.

## Technical Highlights

- **Python Implementation**: Complete ML pipeline with data loading, classification, visualization, and GUI.
  - K-Nearest Neighbors classifier with distance-weighted voting.
  - Tkinter-based GUI for interactive classification.
  - Matplotlib visualizations for data exploration and results.
  
- **C Implementation**: Performance-focused native implementation.
  - Multiple classifiers: KNN, Decision Tree, and SVM.
  - Modular architecture with separate modules for data loading, classification, and evaluation.
  - Makefile included for cross-platform build support.

## Public Scope

The repository includes source code and the Iris dataset. Generated executables, build artifacts, and private course documents are excluded.

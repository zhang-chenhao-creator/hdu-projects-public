# HDU Project Portfolio

This repository collects selected sanitized project code from Chenhao Zhang, Hangzhou Dianzi University.

Focus areas:

- Embedded systems on STM32/STC microcontrollers
- C programming practice projects
- Robotics and embodied AI preparation

Only source code, headers, and necessary project configuration are included. Course reports, presentation files, private data, local editor settings, build artifacts, AI conversation logs, and deferred robotics competition work are intentionally excluded.

## Projects

### Embedded Systems

- `电子硬件/OLED数据曲线绘制`: STM32 OLED audio curve display with FreeRTOS, ADC, UART, and GUI drawing.
- `电子硬件/简易信号发生器`: STM32 waveform generator and measurement demo using PWM, DAC, DMA, ADC, UART, and OLED.
- `电子硬件/声控延时亮灯`: STM32 microphone-triggered delayed lighting project.
- `电子硬件/STM32呼吸灯`: STM32 breathing LED project.
- `电子硬件/六键蜂鸣流水灯`: STM32 key, buzzer, LED, and FreeRTOS practice project.
- `电子硬件/十档五模态流水灯`: STM32 multi-mode LED control project.
- `电子硬件/STC呼吸灯/Debugging`: STC microcontroller breathing LED source and Keil project files.

### C Programming

- `软件开发/成绩管理系统`: Console-based student score management system.
- `软件开发/简单房价预测项目`: C implementation of a simple linear regression practice project. Raw dataset files are not included.
- `软件开发/贪吃蛇游戏`: Console snake game in C.

## Public Boundary

The repository is meant for technical portfolio use. Personal IDs, class information, teammate real names, reports, slides, data files, local tool settings, and generated binaries have been removed from this public version.

# 555 Timer Astable Circuit

This project documents an LM555-based astable oscillator circuit practice. The public repository keeps only a compact project note because the original lab report and PCB document are course deliverables and are not published here.

## Scope

- LM555 astable oscillator design
- Square-wave output target with adjustable duty cycle
- Circuit simulation, schematic capture, PCB layout, soldering, and oscilloscope debugging workflow

## Public Boundary

The original Word report is intentionally excluded from this repository. This folder is kept as a portfolio index entry rather than a full source-code project.

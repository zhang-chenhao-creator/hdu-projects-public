# Six-Button Buzzer LED Controller

STM32F407 firmware that combines key input, buzzer feedback, LED patterns, and FreeRTOS task structure.

## Technical Highlights

- Six-button input handling with embedded debouncing/control logic.
- Buzzer and LED output coordination through GPIO-level firmware.
- FreeRTOS middleware included for task scheduling practice.
- STM32CubeMX and Keil project metadata retained for project reconstruction.

## Public Scope

The public version includes firmware source, configuration files, and vendor dependencies. Build outputs, debug logs, and local IDE state are excluded.

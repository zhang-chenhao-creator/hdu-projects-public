# Ten-Mode LED Patterns

STM32F407 firmware for multi-speed, multi-mode LED pattern control.

## Technical Highlights

- Mode switching logic for multiple LED display patterns.
- Timing control for different speed levels.
- STM32CubeMX-generated GPIO and system configuration.
- Keil project files retained for source-level firmware inspection.

## Public Scope

Only source code, headers, STM32 configuration, startup files, and vendor dependencies are included. Generated binaries and private reports are excluded.

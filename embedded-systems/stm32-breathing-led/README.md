# STM32 Breathing LED

STM32F407 firmware for a breathing LED effect using GPIO and timing control.

## Technical Highlights

- STM32CubeMX-generated firmware layout.
- GPIO and timer-oriented LED brightness control.
- FreeRTOS configuration present for embedded task structure practice.
- Keil/Cube project files retained so the firmware can be inspected in a standard STM32 workflow.

## Public Scope

Only source code, headers, startup files, linker/configuration files, and vendor dependencies are included. Generated binaries and debug outputs are excluded.

# Sound-Triggered Delay Lamp

STM32F407 firmware for a microphone-triggered delayed lighting system.

## Technical Highlights

- ADC sampling path for microphone or analog sound-level input.
- Delay-light control logic built around threshold-triggered behavior.
- FreeRTOS configuration and task-oriented firmware structure.
- CMake/STM32CubeMX project files retained for build context.

## Public Scope

The public version keeps firmware source, headers, STM32 configuration, and required vendor files. Local debugger logs, generated binaries, build folders, and private reports are excluded.

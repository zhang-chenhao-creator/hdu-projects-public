# STC Breathing LED

Breathing LED implementation for an STC microcontroller using 8051-style development files.

## Technical Highlights

- Keil-style project structure for STC development.
- GPIO/PWM-style brightness control logic.
- Delay helper module separated from the main control code.
- Includes STC device header and startup file required for source-level inspection.

## Public Scope

This folder keeps the source-oriented project files only. Generated objects, binaries, and private lab documents are excluded.
